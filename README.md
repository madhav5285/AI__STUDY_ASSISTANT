# 📚 AI Document Processor & Study Assistant

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://aistudyassistant-ewsbmgajycdscda6jhdd4b.streamlit.app)
[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://www.python.org/)
[![Powered by Groq](https://img.shields.io/badge/Powered%20by-Groq-f4722b.svg)](https://groq.com/)

An AI-powered web application built with Python and Streamlit that helps students and professionals prepare for interviews and exams. Upload any PDF document, and the AI will automatically extract the most important information to speed up your study workflow.

**👉 [Try the Live App Here!](https://aistudyassistant-ewsbmgajycdscda6jhdd4b.streamlit.app)**

## ✨ Features
* **Keyword Extraction:** Instantly identifies the most important terms in your document.
* **Concept Explanations:** Provides simple, one-line definitions for key concepts.
* **Code Examples:** Generates practical code snippets for technical topics.
* **Interview Prep:** Drafts custom interview questions based on the uploaded text.

## 🛠️ Tech Stack
* **Frontend:** [Streamlit](https://streamlit.io/)
* **Backend:** Python
* **LLM:** LLaMA3 (via [Groq API](https://groq.com/))
* **Document Processing:** [PyPDF](https://pypi.org/project/pypdf/)
